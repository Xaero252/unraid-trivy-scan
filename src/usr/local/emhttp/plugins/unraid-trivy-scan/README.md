**Trivy Scan**

Scans the images of your Docker containers, and optionally the Unraid OS itself, for known vulnerabilities with a pinned Trivy release and shows one row per CVE, with the affected images, OS files and packages, filters for severity and fix status, a dashboard tile and an optional header tab. The OS's Slackware packages are listed but not CVE-matched (Trivy has no Slackware support). Settings, Trivy Scan.
